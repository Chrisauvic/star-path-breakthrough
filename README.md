# 星轨突围

一个手机竖屏 HTML5 Canvas 小游戏。玩家拖动飞船收集星核，躲避巡航体，通过三段逐渐加速的星际航道。

## 运行

直接用浏览器打开 `index.html` 即可运行。项目没有构建步骤，也不依赖外部网络资源。

本地预览也可以运行：

```bash
node server.js
```

然后打开 `http://127.0.0.1:4188/`。

## 功能

- 开始界面、关卡过渡、失败界面和通关界面
- 五个递进关卡
- 作战简报、通关动画和作战评分页面
- 新手教程、暂停菜单、失败重试流程
- 触控/鼠标拖动控制
- 连击、倒计时、能量脉冲、加分碎片和护盾损耗
- 三类危险：陨石、追踪雷、激光门
- 三类道具：能量碎片、护盾、时间晶体
- Canvas 动画、粒子反馈、屏幕震动和通关星门动画
- Web Audio 音效：点击、收集、受伤、通关、脉冲和背景音乐开关
- 手机竖屏比例和安全区适配

## 文件

- `index.html`：页面结构和游戏界面
- `styles.css`：竖屏布局、HUD 和界面样式
- `game.js`：游戏循环、关卡、碰撞、动画和音效
- `server.js`：本地预览服务器
- `test-smoke.js`：无依赖 smoke test

## 测试

```bash
node --check game.js
node --check server.js
node test-smoke.js
```
